# DEC-0079: IMPL-0031의 누락된 파일 목록을 별도 trace로 정정 기록한다

## Decision
DEC-0078(graph show --mermaid)의 실제 구현은 정확하지만, 구현을 먼저 끝내고 confirm을 나중에 눌러 IMPL-0031의 changed-files가 비어 기록됐다. CLOSED된 태스크는 재추적할 수 없으므로, 4개 대상 파일만 git stash로 격리해 baseline이 정확히 잡히게 한 뒤 이 새 태스크에서 trace를 다시 기록한다. IMPL-0031 자체는 수정하지 않고 그대로 둔다.

## Rationale
- 사용자가 명시적으로 '정정하자'고 요청함
- sduck confirm이 그 시점의 dirty 파일 해시를 baseline으로 스냅샷하고, trace가 baseline과 동일 해시인 파일을 변경 없음으로 취급하는 실제 동작(src/core/v2/git-diff.ts)을 코드로 확인함
