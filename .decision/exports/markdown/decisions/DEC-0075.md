# DEC-0075: 3글자 미만 검색어는 기존 LIKE 경로를 유지하는 하이브리드 검색을 쓴다

## Decision
FTS5 trigram 토크나이저는 3글자 미만 쿼리를 매칭할 수 없음을 직접 확인했다. 2글자 한글 토큰을 버리지 않기 위해 짧은 검색어는 LIKE로, 3글자 이상은 FTS5 MATCH+bm25()로 처리하고 id 기준으로 병합한다.

## Rationale
- DEC-MEMORY-PORTABLE-SEARCH-LOCALE이 2글자 한글 토큰 보존을 이미 결정함
- node:sqlite(Node 22.22)에서 trigram 토크나이저로 2글자 쿼리가 매칭되지 않음을 직접 테스트로 확인
