# DEC-0069: Use deterministic task capsules as a later L2-style projection

## Decision
After bounded retrieval ships, derive one compact task capsule from each closed task's existing brief, decisions, trace, evaluation, scope, and files. Keep capsules as rebuildable cache projections that lead to on-demand graph or source drill-down, not as a new canonical asset or LLM-generated summary.

## Rationale
- This captures the useful L2 scenario concept without storing raw conversations or running extraction models.
- The canonical task and decision Markdown already contains the required source material.
- A compact task-level candidate reduces repeated injection of every decision and trace.
