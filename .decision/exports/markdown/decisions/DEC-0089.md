# DEC-0089: sduck categories suggest/set/list 명령을 추가한다

## Decision
workflow enable/disable/status와 같은 Commander 하위 명령 그룹 패턴으로 categories 명령을 추가한다. suggest는 sduck이 제안하는 범용 기초 후보 목록(고정 상수)을 출력만 한다(파일 쓰기 없음). set <name...>은 policy.json의 categories를 통째로 교체 저장한다(빈 목록이면 CATEGORIES_EMPTY로 거부). list는 현재 설정된 대분류들과 각 대분류에 속한 결정 개수(+미분류 개수)를 recall과 동일한 가시성 규칙(status IN CONFIRMED/DRAFT, task not ABANDONED)으로 집계해 보여준다. set은 정책적으로 그 전에 일반 sduck 워크플로우(work→submit→confirm)로 '왜 이 분류들을 골랐는지'가 먼저 기록되어 있어야 한다는 걸 CLI 도움말/에이전트 규칙 문서로 안내한다(기술적 강제는 아님, sduck remember/close처럼 관례로 안내).

## Rationale
- set 앞에 결정 기록을 기술적으로 강제하려면 이 명령 하나를 위한 특수한 상태 추적이 필요해 과설계가 됨 -- 다른 기계적 명령(remember, close)도 문서/관례로 순서를 안내하는 기존 패턴을 따름
- list의 개수 집계가 recall과 다른 가시성 규칙을 쓰면 '보이는 개수'와 '실제로 recall에 잡히는 개수'가 어긋나 에이전트가 잘못 판단하게 됨
