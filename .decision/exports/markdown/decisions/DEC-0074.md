# DEC-0074: 그래프 확장 깊이는 --depth 옵션으로 노출하고 graph.ts의 MAX_DEPTH(4) 상한을 공유한다

## Decision
1홉 고정 대신 sduck graph show --depth와 동일한 패턴으로 sduck recall --depth <n>을 제공한다. 기본값은 1로 보수적으로 두되 사용자가 최대 4까지 넓힐 수 있다.

## Rationale
- 사용자가 AskUserQuestion에서 hop 수를 고정하지 말고 넓혀두길 원한다고 답함
- DEC-0044가 bounded graph visibility만 허용하고 범용 그래프 쿼리 언어는 배제하므로 기존 MAX_DEPTH 상한을 그대로 재사용
