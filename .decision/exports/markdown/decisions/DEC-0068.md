# DEC-0068: Adopt bounded rank-fused local retrieval, not a general memory hub

## Decision
The highest-leverage TencentDB-Agent-Memory ideas for sduck are ranked fusion of multiple relevance signals, strict retrieval budgets, and progressive drill-down. Implement them locally over the existing rebuildable SQLite cache and canonical Markdown; do not import the server, vector, persona, ACL, or panel architecture.

## Rationale
- sduck already has confirmed decisions, traces, appliesTo matching, graph edges, and a rebuildable SQLite cache, so storage and graph foundations already exist.
- Current recall is exact SQL LIKE over title/summary and current context assembly can include many duplicated or merely recent items.
- TencentDB-Agent-Memory demonstrates that rank fusion plus item, character, and timeout limits is valuable independently of its much larger platform.
