# DEC-0070: Keep memory conflict resolution explicit and confirmation-gated

## Decision
Borrow the memory deduplication idea only as candidate detection: surface highly similar or contradictory prior decisions and let the confirmed brief explicitly carry or supersede them. Do not let an LLM silently merge or rewrite canonical decisions.

## Rationale
- sduck decisions are auditable team intent, not informal conversation facts.
- Existing CARRIED and CONFLICT kinds already provide the correct review boundary.
- An explicit SUPERSEDES graph relation would improve memory hygiene while preserving Git reviewability.
