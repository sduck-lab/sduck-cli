# MEM-0009: categories browse의 500개 상한을 --limit로 노출

## Summary
browseCategory의 하드코딩 500개 상한을 제거하고 limit 매개변수(기본값 DEFAULT_BROWSE_LIMIT=500)로 바꿨다. sduck categories browse에 --limit <n> 옵션을 추가해 recall --depth와 동일한 패턴(기본값+호출별 오버라이드)으로 사용자가 직접 조정할 수 있게 했다.

## Claims
- **DECISION** categories.ts의 browseCategory(projectRoot, category, limit = DEFAULT_BROWSE_LIMIT)로 바꾸고, limit이 1 이상 정수가 아니면 BROWSE_LIMIT_INVALID로 거부한다. 별도의 숨은 상한은 두지 않는다. cli.ts의 categories browse에 --limit <n>(parseInteger로 검증)을 추가했다. (sources: DEC-0092)
- **IMPLEMENTATION** categories.ts/errors.ts/messages.ts(en/ko)/commands/v2/index.ts/cli.ts 수정. v2-categories.test.ts에 limit 오버라이드로 truncated 발생 확인, 잘못된 limit(0/-1/1.5) 거부 확인 케이스 추가. (sources: IMPL-0040)
- **VALIDATION** build/lint 클린, 유닛 171개+e2e 33개 통과. --limit 2로 truncated: true 확인, --limit 0이 Commander 레벨에서 명확히 거부됨을 수동 확인. (sources: EVAL-0022)
