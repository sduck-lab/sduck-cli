# MEM-0001: Source-backed bounded memory

## Summary
Store one stable, provenance-checked Memory Capsule per task; prefer capsules during retrieval; and keep automatically discovered context idempotent and bounded while preserving raw canonical records.

## Claims
- **DECISION** A task has at most one stable Memory Capsule, distilled by the agent and validated by the CLI against canonical sources. (sources: DEC-MEMORY-CAPSULE-BOUNDARY, DEC-MEMORY-AGENT-DISTILLATION)
- **CONSTRAINT** This slice preserves raw task, decision, evidence, trace, and evaluation records; cold archival, deletion, and incremental workspace rewrites remain deferred. (sources: DEC-MEMORY-DEFER-COLD-ARCHIVE)
- **IMPLEMENTATION** Automatic context is reconciled by stable source identity and capped at 40 entries, while explicit files remain idempotent and uncapped; recall and context prefer capsules over represented raw history. (sources: IMPL-0026, DEC-CONTEXT-PERSISTENT-UPSERT, DEC-MEMORY-RECALL-FIRST)
- **VALIDATION** Typecheck, lint, formatting, 152 unit tests, 33 E2E tests, build, and package dry-run passed. (sources: EVAL-0009, IMPL-0026)
