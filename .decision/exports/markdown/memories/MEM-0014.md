# MEM-0014: README에 categories 명령어 문서화, CLAUDE.md에 OMC wiki 충돌 방지 메모 추가

## Summary
이미 구현·확정된 sduck categories(suggest/set/list/browse/tag) 명령이 README에 전혀 문서화되어 있지 않았다(grep 0건). README의 Command reference에 기존 표 스타일 그대로 Categories 섹션을 추가하고 cli.ts의 실제 옵션(--json/--uncategorized/--limit/--stdin)을 옮겼다. 또한 이 세션에서 OMC(oh-my-claudecode)의 wiki_* MCP 도구(add/delete/ingest/lint/list/query/read)가 sduck의 docs/wiki/(sduck wiki build|status|sync|lint 전용)와 이름은 비슷하지만 별개 저장/스키마를 쓰는 시스템임을 확인해, 혼동 방지 메모를 CLAUDE.md의 Evidence-backed Wiki workflow 섹션에 추가했다.

## Claims
- **DECISION** README.md의 'Decision task flow' 표와 'Bounded memory' 사이에 'Categories' 하위 섹션(명령어 표 5줄 + 설명 문단)을 추가한다. CLAUDE.md의 'Evidence-backed Wiki workflow' 섹션 끝에 OMC wiki_* MCP 도구는 docs/wiki/의 대체 인터페이스가 아니라는 점과 docs/wiki/는 오직 sduck wiki build|status|sync|lint로만 관리한다는 점을 명시하는 항목을 추가한다. (sources: DEC-readme-categories-docs, DEC-claude-md-omc-wiki-note)
- **IMPLEMENTATION** README.md에 Categories 표(suggest/set/list/browse/tag, 각 옵션 포함)와 설명 문단을 추가. CLAUDE.md의 Wiki 워크플로우 섹션 마지막에 OMC wiki_* 충돌 방지 문장을 추가. 코드(categories.ts/cli.ts/commands) 및 docs/wiki/ 생성 페이지는 변경하지 않음 -- 순수 문서 변경. (sources: IMPL-0046)
- **VALIDATION** npm run build, npm run lint 모두 클린. README 표의 명령/옵션을 src/cli.ts:507-603의 실제 Commander 정의와 육안 대조해 일치 확인. (sources: EVAL-0027)
