# MEM-0015: sduck 0.8.0 릴리스: README/README.ko 문서 정합성 전면 정비 + 버전 승격

## Summary
Explore 에이전트 감사로 README.md/README.ko.md/cli.ts/package.json을 전수 대조해 15곳+ 격차(README.ko.md의 Categories 섹션 누락, quick start 스크립트에 categories/recall --json/graph --mermaid 미시연, grill complete/evaluate/graph show/recall의 CLI 옵션 문서 누락, EN/KO 패리티 불일치, package.json keywords 부재)를 찾아 모두 수정했다. 사용자가 명시적으로 승인한 대로 package.json/README를 0.8.0으로 올리고 docs/release-0.8.0.md를 신규 작성했으며, 버전을 하드코딩해 검증하던 tests/e2e/v2-cli.test.ts도 함께 갱신했다. 도중 .sduck/sduck-assets/.sduck-version을 맞추려 sduck update를 실행했다가 Wiki policy 활성화·CLAUDE.md 관리 블록 초기화 등 범위 밖 부작용이 발생해 git checkout으로 즉시 원복하고, 그 파일은 이번 범위에서 건드리지 않기로 했다.

## Claims
- **DECISION** README.ko.md에 README.md와 1:1 대응하는 Categories 섹션을 추가하고, 양쪽 README의 Quick start/Command reference/EN-KO 패리티 격차를 모두 수정하며, package.json에 keywords를 추가하고 버전을 0.8.0으로 올려 docs/release-0.8.0.md를 신규 작성한다. (sources: DEC-readme-ko-categories-parity, DEC-readme-quickstart-parity, DEC-command-reference-completeness, DEC-package-json-keywords, DEC-version-bump-0-8-0)
- **IMPLEMENTATION** README.md/README.ko.md: Categories 섹션(KO 신규), quick start에 categories/recall --json/graph --mermaid 추가, work/--record-depth·grill complete --changed-assumption·evaluate --limitation/--json·graph show --mermaid·recall --depth/--json·-V/--version·legacy 명령 옵션을 표에 반영, EN/KO 패리티 문구 수정. package.json에 keywords 추가 및 버전 0.7.0→0.8.0. docs/release-0.8.0.md 신규 작성. tests/e2e/v2-cli.test.ts의 하드코딩된 버전 assertion을 0.8.0으로 갱신. sduck update로 유발된 Wiki policy 활성화와 CLAUDE.md/AGENTS.md/GEMINI.md/.decision/policy.json/.sduck-version 변경은 git checkout으로 전부 원복해 범위 밖 부작용을 제거했다. (sources: IMPL-0047)
- **VALIDATION** npm run lint, typecheck, build 모두 클린. npm run package:check(npm pack --dry-run)로 0.8.0 패키징 정상 확인. 전체 테스트 스위트 unit 173/173, e2e 33/33 통과. (sources: EVAL-0028)
