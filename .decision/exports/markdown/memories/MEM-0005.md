# MEM-0005: recall RRF 융합: FTS bm25 + LIKE + 그래프 hop-거리 순위

## Summary
recall()의 decisions/traces가 FTS 우선 이어붙이기 대신 FTS bm25 순위, LIKE 순위, 그래프 hop-거리 순위(시드 제외) 3개 리스트를 RRF(k=60)로 융합한 순서를 쓰도록 바꿨다. graph.ts의 expandGraph는 노드를 알파벳순이 아니라 (hop level, id)로 정렬해 이 순위 신호를 실제로 제공한다.

## Claims
- **DECISION** search.ts에 순수 함수 reciprocalRankFusion/rankByRrf(k=60)를 추가하고, recall()은 FTS bm25 순위·LIKE 순위·그래프 hop-거리 순위(시드 자신은 제외) 3개 리스트를 이 함수로 융합해 decisions/traces 최종 순서를 정한다. 그래프에서만 발견된 decision/trace는 CONFIRMED/미폐기 필터로 DB에서 보강 조회한다. RecallResult 필드 구성은 그대로다. (sources: DEC-0082, DEC-0083)
- **DECISION** graph.ts expandGraph의 노드 정렬을 알파벳순에서 (BFS level 오름차순, id 오름차순)으로 바꿨다. GraphExpandResult/GraphShowView 타입과 graph show 출력 포맷은 그대로 유지된다. (sources: DEC-0084)
- **CONSTRAINT** 그래프 랭킹 리스트에서 시드 자신(top FTS/LIKE 히트)을 반드시 제외해야 한다 -- 시드는 BFS에서 항상 level 0으로 들어가 그래프 순위에서도 자동 1위를 먹는데, 이미 FTS/LIKE 신호로 높은 점수를 받은 항목이 그래프 신호까지 중복으로 받으면 실제로 그래프를 통해서만 발견된 1-hop 이웃(원래 이 기능의 목적)이 그 뒤로 밀려난다. 벤치마크로 이 이중 계산 버그를 직접 재현: graph-edge pair의 MRR이 0.750->0.292로 퇴행했다가, 시드 제외 필터를 추가하자 0.750로 회복됨. (sources: DEC-0083)
- **IMPLEMENTATION** search.ts: reciprocalRankFusion/rankByRrf 추가. graph.ts: BFS에서 level 추적, (level,id) 정렬. recall.ts: ftsDecisionIds/likeDecisionIds/ftsTraceIds/likeTraceIds를 원시 순위 배열로 뽑아내고, memories+top10 FTS/LIKE decision·trace id를 그래프 시드로 써서 expandGraph 1회 실행 후 시드를 제외한 kind='decision'/'trace' 노드를 3번째 순위 리스트로 사용. fetchDecisionsByIds/fetchTracesByIds로 그래프 전용 히트를 보강 조회. tests/unit/v2-search.test.ts 신규(rankByRrf 4케이스), tests/unit/v2-recall.test.ts에 두 태스크에 걸친 CARRIED 인용으로 그래프 전용 승격을 검증하는 케이스 추가. tests/e2e/v2-cli.test.ts의 graph show 알파벳순 단정을 (level,id) 계약에 맞게 수정. (sources: IMPL-0035)
- **VALIDATION** build/lint 클린, 유닛 166개+e2e 33개 통과. sduck-recall-bench로 sdcuk-cli 자체 재측정: graph-edge(2쌍) MRR이 시드-제외 수정 후 depth-0과 동일한 0.750으로 회복(수정 전엔 0.292로 퇴행했었음), 전체 Hit@5 68.4%는 depth 0/1/2/4 전부 동일, no-graph-edge 17쌍 중 1건만 Hit@10 기준 rank 9->11로 근소 하락. adieum-api(그래프 엣지 0개 corpus)는 28.6%/MRR 0.308로 이전 불용어-수정 기준선과 완전히 동일(회귀 없음, 그래프 신호가 개입할 여지가 없는 corpus라 중립적). (sources: EVAL-0018)
