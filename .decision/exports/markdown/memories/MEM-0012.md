# MEM-0012: 모든 결정의 sourceRefs를 그래프 엣지로 -- CARRIED_FROM/CITES 구분

## Summary
rebuild.ts의 insertGraph가 지금까지 kind==='CARRIED'인 결정에서만 그래프 엣지를 만들어, 실제 인용의 대부분(sdcuk-cli 28/30쌍, adieum-api 7/7쌍)이 그래프에 전혀 반영되지 않고 있었다. 이제 모든 결정의 sourceRefs(DEC- 접두만)를 엣지로 만들되 CARRIED는 CARRIED_FROM(강한 승계), 그 외는 새 CITES(일반 참조)로 구분한다. recall()의 그래프 hop-거리 신호가 처음으로 대부분의 실제 인용에 작동하게 됐다.

## Claims
- **DECISION** insertGraph가 decision.sourceRefs를 kind 조건 없이 전부 순회하되 DEC- 접두 참조만(비-결정 참조 제외) 엣지로 만든다: kind==='CARRIED'면 CARRIED_FROM, 그 외는 CITES. GRAPH_PROJECTION_VERSION을 v2->v3로 올려 기존 캐시를 강제 재구축시킨다. recall.ts/graph.ts는 이미 엣지 kind와 무관하게 순회하므로 변경 불필요. (sources: DEC-0096)
- **VALIDATION** build/lint 클린, 유닛 172개+e2e 33개 통과. sduck-recall-bench로 코드 스왑 기반 true old-vs-new 비교: sdcuk-cli(30쌍) Hit@10 56.7%->66.7%(+10.0pp), MRR 0.257->0.269. adieum-api(7쌍) Hit@5 57.1%->71.4%, Hit@10 57.1%->100.0%(+42.9pp), MRR 0.238->0.314. adieum-api broad pair(8쌍, 참고용)도 Hit@10 50.0%->75.0%로 개선. graph-edge(CARRIED) 그룹은 이번 변경과 무관해 100%/0.750 그대로 유지, 회귀 없음. (sources: EVAL-0025)
